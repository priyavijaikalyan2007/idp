### Added

### Fixed

- 2026-06-10 — Production incident root-caused: the first deploy of the SPI image coincided with Hibernate `42P01 relation does not exist` errors (`offline_user_session`, `realm`) and the SPI image was suspected. Forensic reproduction with the exact failed image ID under the production entrypoint (`start --optimized`, vanilla-initialised schema, 6+ hour soak) showed the image fully healthy, and `kc.sh show-config` differs from the vanilla image by only the provider-registration line. Verdict: transient on the Neon pooler/compute side (failures clustered by time window — a known-good rollback image also failed inside it). No code change required; speculative JAX-RS edits made under the disproved theory were reverted. See `CONVERSATION.md` (2026-06-10 session) and `AGENT_INSIGHTS.md` §5. Follow-ups recorded as TD-007 (pin base image by SHA digest) and TD-008 (`run.sh --prod` mode). TD-003 (bootstrap admin password binding) verified resolved on the same deploys.

- 2026-06-09 — End-of-session documentation sweep. `AGENT_INSIGHTS.md` (engineering lessons across Keycloak SPI integration / test harness / build tooling / process), `TECH_DEBT.md` (TD-001 through TD-006 with status, priority, implementation plans, and triggers to revisit), `CONVERSATION.md` (session narrative log of the MCP SPI build from per-realm contract decision through deployable image). All 27 Java files and 6 shell scripts audited for SPDX + marker-block compliance and passed. Test .java files intentionally omit the marker block per MARKERS.md §9 exception for non-workflow utility files.
- 2026-06-09 — Test-run JVM noise eliminated. Surefire/Failsafe now run with `-Djava.util.logging.manager=org.jboss.logmanager.LogManager` (silences Keycloak's "LogManager accessed before property was set" ERROR), `-javaagent:${net.bytebuddy:byte-buddy-agent:jar}` (silences the three byte-buddy "dynamic agent loading" warnings under JDK 21), and `-Xshare:off` (silences the JVM CDS bootstrap-classpath warning). Added the `maven-dependency-plugin:properties` execution so the byte-buddy-agent JAR path resolves into a property. Log output now uses the proper JBoss format (`ISO timestamp LEVEL [class] (thread) message`). The ERROR/WARN lines that still appear in test output are the SPI's own log statements from test cases deliberately exercising error paths — they prove the logging is wired correctly.
- 2026-06-09 — Image tagging upgraded. `build.sh` now applies a sortable unique versioned tag of the form `YYYYMMDDhhmmss-<git-commit>` (UTC) plus a moving `:latest` tag in the same `docker build` call. `push.sh` pushes both tags. `build.json` records `build_timestamp` and `latest_tag` alongside the existing `remote_tag`. Each build remains uniquely identifiable in Artifact Registry even when the git commit is unchanged (e.g., re-builds for config tweaks).
- 2026-06-09 — Completed the AGENTS.md script inventory. `clean.sh` (remove all build artifacts), `run.sh` (run the locally-built Keycloak image against a postgres sidecar on http://localhost:10000), `deploy.sh` (chain build.sh + push.sh + `gcloud run deploy` + log tail), `prune.sh` (delete inactive Cloud Run revisions and old Artifact Registry image versions, preserving any image still referenced by ANY revision).
- 2026-06-09 — Slice 6 of the Keycloak MCP SPI: build pipeline + deployment config. `build.sh` patched to compile the SPI (`mvn package -DskipITs`), stage the JAR to `/target/providers/`, and pass `SPI_VERSION`/`VCS_REF`/`BUILD_DATE`/`IMAGE_VERSION` build-args. `test.sh` created (runs `mvn verify` in `src/providers/` — full unit + Testcontainers IT). `Dockerfile` env-var comments updated to per-realm naming. `cloudrun.yaml` adds a commented per-realm HMAC env-var stanza (uncomment when secrets exist) and fixes a pre-existing `KC_BOOTSTRAP_ADMIN_PASSWORD=` typo (trailing `=` was making the env-var name invalid).
- 2026-06-09 — `HandoffTokenSigner` migrated from the deprecated `JWSBuilder.hmac256(byte[])` path to the modern `MacSignatureSignerContext` + `KeyWrapper` + `JWSBuilder.sign(SignatureSignerContext)` API. Algorithm identifier hardcoded as RFC 7518 wire constant `"HS256"` to avoid the also-deprecated `org.keycloak.jose.jws.Algorithm` enum. SignatureSignerContext cached per realm. Compilation now warning-free with `-Dmaven.compiler.showDeprecation=true`. ADR-008.
- 2026-06-08 — Slice 5 of the Keycloak MCP SPI: Testcontainers integration test. `McpSpiLoadingIT` spins up Keycloak 26.6.0 in Docker with the freshly-built SPI JAR mounted via `withProviderLibsFrom`, hits the mcp-picker-callback endpoint, and asserts 400 missing_token — proving JAR registration, META-INF/services wiring, and handler dispatch. Runs in ~ 39 s on the verify phase. Requires Docker on the build host.
- 2026-06-08 — Slice 4 of the Keycloak MCP SPI: ResourceProvider (resume). `McpPickerCallbackResourceProvider` + factory. JAX-RS endpoint at `/realms/{realm}/mcp-picker-callback` validates picker-result JWT, finds the suspended auth session, writes user-session notes, and 302s back to `AuthenticationFlowURLHelper.getLastExecutionUrl` to resume the flow. Registered in `META-INF/services/org.keycloak.services.resource.RealmResourceProviderFactory`. 22 new tests; 108/108 cumulative. Added `kc_client_id`, `kc_tab_id`, `auth_session_id` claims to `PickerResultToken` so the callback uses HMAC-signed correlation fields instead of trusted-query-param tampering.
- 2026-06-08 — Slice 3 of the Keycloak MCP SPI: Authenticator (suspend). `McpTenantPickerAuthenticator` + `McpTenantPickerAuthenticatorFactory`. Reads per-realm `yourapp.web.host` from Authenticator config, signs picker-request with per-realm HMAC, 302s via `context.challenge(Response.seeOther(...))`. Registered in `META-INF/services/org.keycloak.authentication.AuthenticatorFactory`. 27 new tests; 86/86 cumulative. `oauth_state` relaxed from required to optional in both token builders.
- 2026-06-08 — Slice 2 of the Keycloak MCP SPI: scope override mapper. `McpScopeOverrideMapper` reads user-session note `yourapp_scopes` and overrides the access-token `scope` claim. Registered in `META-INF/services/org.keycloak.protocol.ProtocolMapper`. 10 unit tests pass; 59/59 cumulative.
- 2026-06-08 — Slice 1 of the Keycloak MCP SPI: JWT primitives. `McpSpiConfig` + `McpSpiConfigException` (per-realm env var resolution); `HandoffValidationException`; `ReplayCache` (bounded LRU); `PickerRequestToken` + `PickerResultToken` (snake_case wire, Builder pattern); `HandoffTokenSigner` + `HandoffTokenValidator` (Keycloak bundled `JWSBuilder.hmac256` + `HMACProvider.verify`; per-realm key cache; current+previous overlap). 49 unit tests pass; Jacoco 97% instruction coverage.

### Changed

- 2026-06-10 — `build.json` is no longer tracked by git (added to `.gitignore`). It is volatile build output — regenerated with fresh timestamps/tags by every `./build.sh` and deleted by `./clean.sh` — so tracking it kept the working tree perpetually dirty.
- 2026-06-10 — `cloudrun.yaml` refreshed to the live revision shape: `KC_DB_PASSWORD` and `KC_BOOTSTRAP_ADMIN_PASSWORD` bound from Secret Manager, and the per-realm `YOURAPP_MCP_HANDOFF_HMAC_KEY__YOURAPP_PROD` secret binding active (previously a commented stanza).
- 2026-06-07 — MCP handoff HMAC contract is now per-realm. Environment variables `YOURAPP_MCP_HANDOFF_HMAC_KEY__<REALM>` (and optional `_PREVIOUS__<REALM>`) replace the prior single-instance variables. `YOURAPP_WEB_HOST` env var removed; YourApp web hostname moved to per-realm Authenticator config property `yourapp.web.host`. Updated `specs/keycloak.spi.mcp.md` (v0.4), `specs/keycloak.prd.md` §16, `specs/keycloak.mcp.md`, `specs/keycloak.web.mcp.md`.
